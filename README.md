# Bye Bye Duo

**English Practice** — приложение для тех, кто начинает учить английский на Mac. Инструкции и разбор ошибок написаны по-русски. В стартовом курсе ты учишься рассказывать о привычках и о том, что происходит прямо сейчас. Например, *I usually take the bus, but today I’m walking.*

Первый урок можно пройти офлайн. Если подключить свой аккаунт Codex, приложение также сможет проверять свободные ответы и составлять уроки на интересные тебе темы.

## Как запустить на Mac

Приложение работает на **macOS 15 и новее**. Для сборки из исходников понадобится полный Xcode со Swift 6.2 или новее.

1. На странице репозитория нажми **Code → Download ZIP** и распакуй архив.
2. Открой в Xcode файл `English.xcodeproj`. В верхней панели выбери схему **English Practice** и устройство **My Mac**.
3. Нажми **⌘R**. Xcode соберёт и откроет приложение. Стартовый курс, голоса и словари уже входят в проект.

## Первый урок

При первом запуске откроется мастер настройки. Чтобы сразу попробовать английский, выбери **English Practice → Вернуться к плану** в строке меню macOS. В разделе **Present Simple** открой урок **«Привычки и факты»**.

В одном из заданий встретится фраза *She ___ (work) from home on Fridays.* Впиши ответ и нажми **«Проверить»**. Приложение объяснит, почему здесь подходит *works*. В этом же уроке встретятся карточки со словами раздела. Чтобы сделать перерыв, нажми **«Сохранить и выйти»**. При следующем открытии урок продолжится с сохранённого шага.

В следующих разделах можно потренировать Present Continuous, послушать фразы и пройти контрольные. Для дополнительной тренировки слов открой меню занятия и выбери **«Повторить слова раздела»**.

## Персональный курс с Codex

1. Установи Codex CLI и выполни в Терминале `codex login`, чтобы войти в свой аккаунт. [Инструкция по установке Codex CLI](https://learn.chatgpt.com/docs/codex/cli)
2. Открой мастер при первом запуске или через **English Practice → Настроить обучение…**. На шаге подключения скопируй команду и выполни её в Терминале. Команда подключит запущенную копию приложения к Codex через локальный сервер MCP.
3. Нажми **«Проверить подключение»**, выбери дневную цель и пройди входной тест из 20 заданий. По его результатам можно выбрать темы и составить первый план.

Можно попросить об уроке и прямо в чате Codex. Начни новый чат после подключения и попроси подготовить занятие на бытовую тему.

> Добавь в English Practice урок для начинающего на тему «В кафе». Хочу научиться заказывать напиток и спрашивать цену. Добавь короткий диалог, аудирование и карточки со словами раздела.

Урок появится в плане на твоём Mac. Codex также может прочитать последнюю сданную попытку и подготовить повторение по ошибкам. Если приложение не нашло Codex CLI, путь к нему можно указать в **Настройки → Подключение Codex**.

## Прогресс и настройки

- **Статистика → Обучение** показывает проверенные упражнения за 7, 30 или 90 дней, включая карточки и проверенные ответы в черновиках.
- **Статистика → Агент** показывает, на какие задачи приложение вызывало Codex и сколько токенов сообщил CLI.
- **Настройки → Агент** задаёт модель и уровень рассуждения для генерации и проверки. Режим «По умолчанию для уроков» выбирает GPT-6.2 Sol с низким effort при наличии в каталоге. Здесь же можно изменить размер раздела и английские шаблоны промптов. Приложение и MCP читают настройки из одной учебной базы. Начатый план сохраняет свой выбор.
- **Настройки → Ежедневное напоминание** позволяет указать местное время, например `9:30`, или выключить уведомление. Разовое напоминание о домашней работе настраивается в самой работе.
- **Настройки → Озвучка** позволяет выбрать голос и прослушать пример. Синтез речи работает офлайн.

Курс, черновики и история занятий хранятся на твоём Mac в `~/Library/Application Support/English Practice/course.sqlite3`. Закрытые упражнения проверяются на устройстве. Для проверки свободного ответа приложение отправляет Codex условие и твой ответ. Для персонального плана оно передаёт выбранные темы, учебную цель и контекст курса. Эти запросы используют твой аккаунт Codex.

## Для разработчиков

Интерфейс написан на SwiftUI, учебные данные хранятся в SQLite. Для экспериментов с отдельным курсом задай переменную окружения `ENGLISH_DATA_DIR` с путём к тестовой папке и для приложения, и для его MCP-сервера.

Встроенный MCP поддерживает следующие инструменты для работы с курсом.

| Инструмент | Назначение |
| --- | --- |
| `list_course` | Посмотреть структуру курса и найти идентификаторы разделов |
| `generate_section` | Поручить учебной модели подготовить и сохранить раздел по теме и цели, получить идентификатор запроса |
| `get_generation_status` | Узнать результат фоновой генерации и идентификаторы готовых уроков |
| `add_lesson` | Импортировать готовый урок, домашнюю работу, историю или контрольную |
| `add_vocabulary` | Добавить слова с переводами, примерами и допустимыми ответами |
| `get_study_context` | Получить последнюю сданную попытку и подобрать повторение |

Требования к учебным материалам описаны в [AGENTS.md](AGENTS.md), а правила интерфейса — в [DESIGN.md](DESIGN.md).

### Встроенная озвучка

Для синтеза речи используются модель [tiny-voca](https://huggingface.co/n4ze3m/tiny-voca) и движок [voca](https://github.com/sultson/voca/tree/03f91ae073fce4fce8852323efe3345dfe4048f5). Лицензии модели, движка и словарей находятся в [English/TinyVoca](English/TinyVoca), лицензии шрифтов — в [English/PlanFonts](English/PlanFonts).

<details>
<summary>Сборка встроенного движка для macOS</summary>

Готовый универсальный исполняемый файл находится в `English/Helpers/voca`. Xcode копирует и подписывает его при сборке приложения. Для пересборки с Rust 1.94 из указанной выше версии исходников выполни в каталоге voca:

```sh
rustup target add --toolchain 1.94.0 aarch64-apple-darwin x86_64-apple-darwin
MACOSX_DEPLOYMENT_TARGET=15.0 cargo +1.94.0 build --release --locked -p tiny-voca --bin voca \
  --target aarch64-apple-darwin --target x86_64-apple-darwin
lipo -create target/{aarch64,x86_64}-apple-darwin/release/voca -output voca
```

Веса и словари в `English/TinyVoca` взяты из `voca-data.tar.gz` [релиза v0.1.0](https://github.com/sultson/voca/releases/tag/v0.1.0). SHA-256 архива — `c273756ca9c61f800b58921e18f07a4ca405654f4d56e7ab1c023e751a6aad7a`. Лицензии входят в комплект.

</details>
